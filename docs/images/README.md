# Images used by the top-level README

`README.md` references `interrupts.png`, the Interrupts screen with a completed plan. Keep it at native
resolution - the labels are the point, and a scaled-down screenshot cannot be read.

Worth capturing, in this order of value:

1. **Interrupts, with a plan visible** - shows the cores, the devices and the per-row evidence chips.
2. **Home, verdict line** - shows the app answering its own question first.
3. **The interrupt check results** - the per-CPU counter table, which is the proof a move happened.

Save as PNG, no browser chrome, no desktop background. A screenshot of the window alone.
