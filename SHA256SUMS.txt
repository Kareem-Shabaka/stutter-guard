# Stutter Guard - SHA-256 checksums
#
# Every release also carries StutterGuard.exe.sha256 next to the binary. That file is generated
# on the build machine from the exact bytes uploaded, so it always matches the download. Prefer it.
#
# Verify a download on Windows:
#   certutil -hashfile StutterGuard.exe SHA256
#
# ---- v1.2.0 (superseded when a newer release is published; each release carries its own .sha256) ----
01752CF8BCFAF8346516CFAC14DA0E1D2B468EBAACCC0923F0BAFBF39BC25B89  StutterGuard.exe
#
# ---- What is measured, and what is not ----
#
# Builds are reproducible in a fixed environment. Measured 2026-11-15 on .NET SDK 10.0.402,
# win-x64, on this very commit: two clean publishes, into two different directories, produced
# 65,446,991 bytes with the same SHA-256 (E36FE73D9E6F4DEDC5D41FDD6215DC05776BC3F2D1C0809B7FD6054F6B1D5122).
# `build.cmd --verify-repro` repeats that check on your machine.
#
# That does not mean your own build must equal a released hash: a different SDK patch level,
# runtime pack or output path can change the bytes. So verify a download against the .sha256
# published with that release, never against a hash you produced yourself.
